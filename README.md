# NoPip Toolkit

Landing page: https://aayush10shah-tech.github.io/nopip-toolkit/

`bulk_rename.py` is a free sample from the toolkit. It's one file, uses only the standard library, and runs on Python 3.9+:

```
python bulk_rename.py ./photos --match "IMG_(\d+)" --replace "trip_\1"          # preview
python bulk_rename.py ./photos --match "IMG_(\d+)" --replace "trip_\1" --apply  # do it
```

The full kit (16 scripts, a guide and scheduling recipes) is at https://aayushshah.gumroad.com/l/nopip
